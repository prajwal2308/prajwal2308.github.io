VACS

macOS · Swift Aug 2026

A native macOS disk cleaner built specifically for developers — the one audience for whom generic “junk files” is exactly the wrong abstraction. Xcode DerivedData, Docker VM disks, Ollama weights, and Playwright browsers look identical to a generic cleaner. VACS identifies each in plain English and gives you the safe, correct way to reclaim space.

  • 96 audited paths, 8 developer categories, 0 network requests. Four safety levels — safe, check first, command-only, never — enforce what the UI will even offer to touch.
  • Trash by default. Nothing is silently erased; permanent deletion only ever happens when explicitly chosen, and no step anywhere asks for sudo.
  • For live Docker VMs and installed packages, it copies the official command (docker system prune -a) rather than risking corrupting active state.

LLMOps Control Plane

Live Aug 2026

A self-hostable gateway sitting between your applications and OpenAI, Anthropic, Gemini, Bedrock, Fireworks, and xAI — exposing an OpenAI-compatible API so nothing upstream requires modification.

  • Complexity-based routing automatically directs low-complexity prompts to cost-efficient models, triggering fallback chains across provider tiers if an API errors.
  • Per-request telemetry — latency, token usage, cost — streamed to a real-time SSE dashboard, with automated alerts for cost or error spikes.
  • Inbound prompt-injection detection & outbound PII redaction.
  • Stateless, horizontally scalable architecture provided as Docker container, Helm chart, and Terraform module with OTel tracing.
